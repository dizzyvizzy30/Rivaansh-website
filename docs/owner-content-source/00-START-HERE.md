# Start here

This folder follows the same order as the website. Keep every numbered folder and photo-folder name unchanged so we can place each answer and image correctly.

## Edit a page in Google Drive

1. Open the numbered folder for that website page.
2. Double-click `EDIT-IN-GOOGLE-DRIVE.docx`.
3. If a preview opens, choose **Open with Google Docs** at the top.
4. Type below each **Your answer** heading.
5. Google saves the changes automatically in the same Word file.
6. Add `COMPLETE` to the file name when the page is finished.

The editable questionnaires use Word format because Google Drive can open, edit, and save `.docx` files directly in the browser.

## Add photos to a page

Live photo reference: `https://rivaanshent.com/pages/photos-needed.html`

This unlisted page shows every requested photo, its orientation, minimum size, priority, website use, and matching upload folder.

1. Open the page folder.
2. Open its `photos` folder.
3. Open the folder matching what the photo shows.
4. Read `PHOTO-INSTRUCTIONS.txt`.
5. Drag up to three original photos into that folder.

The photo filename does not matter. Do not rename the photo folder.

## Add documents

- Put official printed details in `00-shared-site-details/reference/`.
- Put existing operation instruction sheets in `05-before-and-after-surgery/handouts/`.

## Share the completed work

Share the complete `owner-content` folder through Google Drive. Keep access **Restricted** and grant access only to the owner, authorized centre staff, and the website team.

## Privacy

- Do not include identifiable patients.
- Do not include patient names, phone numbers, reports, prescriptions, or screen data.
- Staff shown in photos must agree to website publication.
- Upload original images rather than screenshots or WhatsApp-compressed copies.
