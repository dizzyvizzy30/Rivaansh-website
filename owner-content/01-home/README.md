## What we need from you
1. Answer the questions in `text.md` (type under each "Your answer").
2. Put photos in the folders below — the folder name tells us where each photo goes.

- `hero-slideshow-photos/` — 3–5 wide (landscape) photos for the large rotating banner at the top. At least 1920 px wide. Calm, uncluttered, faces in the upper part of the frame work best.
- `specialist-portraits/` — One head-and-shoulders photo per team member, plain background. Name each file after the person, e.g. `dr-tanay-parikh.jpg`.

**Photo tips:** original files straight from the phone/camera (no WhatsApp-compressed copies if possible), sharp and well lit,
no watermarks. Name each file after what it shows, e.g. `reception-waiting-area.jpg`. No identifiable patients unless you
have their written consent.
