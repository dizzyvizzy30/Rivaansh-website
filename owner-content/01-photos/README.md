# Photos (one phone photo session)

**Website pages:** Home, Doctor & Clinic, Visit Us

**Time needed:** about 1 hour

**Developer note:** updates go into `src/assets/images/ (chosen photos are copied there by the developer)`.

Put each photo in the folder named after what it shows. The website resizes everything automatically, so don't worry about file size.

## What to do
1. Answer the questions in `text.md` (type under each "Your answer").
2. Put files in the folders below — the folder name says what goes in it.

- `doctor-portrait/` — A clear, upright photo of Dr. Tanay S Parikh — plain background, good light, head and shoulders or seated at the desk.
- `exterior-signboard/` — The Centre Point building, the entrance, and the Rivaansh signboard (helps patients find the clinic).
- `reception/` — Front desk and waiting area.
- `consultation-room/` — The examination chair and ENT unit.
- `equipment/` — Endoscope, microscope, audiometry booth, etc. — one photo per item, file named after it.
- `operation-theatre/` — Only if the clinic has its own operation theatre — staff only, no patients.

**Photo tips:** take photos in daylight with the phone held steady; send the original files (not WhatsApp-compressed
copies) if possible; no watermarks. Name each file after what it shows, e.g. `reception-waiting-area.jpg`.
**Consent:** no identifiable patients. Staff who appear in photos must agree to their photo being on the website.
