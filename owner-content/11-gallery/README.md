# Gallery

**Page:** /pages/gallery.html

**Developer note:** updates go into `src/data/gallery.ts (+ photos in src/assets/images/clinic/)`.

## What the page shows now
- Four photos: doctor at desk, endoscopy procedure, operation theatre team, microscope ear surgery. Each opens full screen.

## What we need from you
1. Answer the questions in `text.md` (type under each "Your answer").
2. Put photos in the folders below — the folder name tells us where each photo goes.

- `clinic-exterior-and-signboard/` — Building, entrance, signboard, directions landmarks.
- `reception-and-waiting-area/` — Front desk and seating.
- `consultation-rooms/` — Examination chair, ENT unit, doctor at work.
- `diagnostic-equipment/` — Audiometry booth, endoscope, microscope, etc.
- `operation-theatre/` — OT with staff only (no patients visible).
- `team/` — Doctors and staff, individually or together.
- `events-and-health-camps/` — Awareness talks, camps, certificates/awards.
- `videos/` — Optional short clips (under 1 minute, landscape). A clinic walkthrough works well.

**Photo tips:** original files straight from the phone/camera (no WhatsApp-compressed copies if possible), sharp and well lit,
no watermarks. Name each file after what it shows, e.g. `reception-waiting-area.jpg`. No identifiable patients unless you
have their written consent.
