# Owner content — page-by-page review

This folder is for the clinic to review the website **one page at a time** and send back photos and facts.
Every page of the website has its own numbered folder, named after the website menu.

## How to fill it in
1. Open the website page listed in the table below and its folder side by side.
2. Read the folder's `README.md` — it says what the page shows today and what is needed.
3. Answer the questions in `text.md` (type under each "Your answer").
4. Drop photos into the sub-folders. **The sub-folder name is where the photo will be used**, so put each photo in the right one
   and name the file after what it shows (`reception-waiting-area.jpg`, `dr-tanay-parikh.jpg`).
5. Send the folder back (zip it, or share it via Google Drive). Don't worry about sizes or formats — the website resizes and
   optimises every photo automatically.

**Photo tips:** original files straight from the phone/camera (no WhatsApp-compressed copies if possible), sharp and well lit,
no watermarks. Name each file after what it shows, e.g. `reception-waiting-area.jpg`. No identifiable patients unless you
have their written consent.
